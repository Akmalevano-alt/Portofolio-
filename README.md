# Portofolio

Website portofolio statis (HTML, CSS, JS) — responsif, tema gelap/terang, bahasa ID/EN.

## Yang perlu kamu isi
- **CV**: taruh PDF di `CV/CV-Akmal-Evano-Wisnu-Putra.pdf` (tombol "Unduh CV" di beranda).
- **LinkedIn**: ganti `username-kamu` di `contact.html`.
- **Teks / terjemahan**: semua ada di `i18n.js` (bagian `id` dan `en`).
- **Sertifikat baru**: ganti gambar & judul di `certificates.html`.
